# TALAAN

QR attendance for a class section. It runs in the browser, works offline, and can be installed on a phone like an app.

Live app: https://lestermanota.github.io/TALAAN/

## What it does

- Scan student ID QR codes with the phone camera, front or back (the choice is remembered, also in kiosk mode), or mark attendance by hand
- Classes, weekly schedule, holidays, and a printable report
- Works offline. Time-ins wait on the phone and sync to Google Sheets when there is internet
- Optional email receipts to students
- Light and dark mode, and a layout that adapts to phones, tablets and desktop, in portrait or landscape

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole app (HTML, CSS and JavaScript in one file) |
| `sw.js` | Service worker that keeps the app working offline |
| `manifest.webmanifest` | Lets the phone install it as an app |
| `jsQR.min.js` | QR code reader library |
| `icon-*.png`, `apple-touch-icon.png` | App icons |

## Updating the app

1. Replace the changed files in this repository (Add file > Upload files).
2. If you replaced `index.html`, also change the `VERSION` in `sw.js` (for example `talaan-v71` to `talaan-v72`). That is what tells phones to download the new files.
3. Wait for GitHub Pages to finish deploying. Open the app; when it shows "New version ready", tap **Reload**.

If the app was installed to the home screen before the manifest changed, remove it and install it again so the phone reads the new manifest.

## Google Sheets and email receipts

Syncing and receipts use a Google Apps Script that is generated by the app.

1. In the app, open **Settings** and copy the script.
2. Paste it into a new Apps Script project attached to your Google Sheet, then **Deploy** it as a web app.
3. After every app update that changes the script, copy it again and **Deploy a new version**. The Test receipt button tells you if the deployed script is out of date.

Receipts (set these in Apps Script > Project Settings > Script properties):

| Property | Meaning |
| --- | --- |
| `EMAIL_CONFIRM` | Set to `on` to email receipts |
| `RECEIPT_DELAY_MIN` | Minutes to wait before a receipt is sent. Default `10`; `0` sends at once |

A receipt is sent about 10 minutes after time-in, so a mistake can still be fixed or undone first. Each receipt also says who recorded it (**Admin** or **Secretary**, with the name they signed in with). If a record is changed after its receipt went out, the student gets an **Updated** or **Voided** receipt that names who made the change. The class Sheet is always the official record, and the receipt's QR code shows the latest status. The script keeps its queue in a hidden tab named `Receipt Queue`.

A free Gmail account can send about 100 emails a day.

## Where data is kept

Student names and attendance records are saved in the browser on the teacher's phone. When Google Sheets sync is on, they are also written to the Google Sheet connected through the Apps Script, and the optional Drive backup saves a copy in the teacher's own Google Drive. The offline cache only stores the app's own files, fonts and the QR library.
